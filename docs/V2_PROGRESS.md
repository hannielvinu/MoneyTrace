## Things I found and fixed that you should know about
- The old screenshot "OCR" always returned ₹18,500 / `kyc-update.pay@ybl`; risk score and confidence were fixed at 0.94;
  dashboard clusters were hard-coded; any narrative containing "kyc" was matched to TXN784219, and the entity extractor
  invented a scammer phone / bank account for KYC-type reports. The ADK path no longer does any of this (the legacy
  engine is kept unchanged behind `AGENT_ENGINE=legacy`).
- A first RAG run scored 100 % "grounded" because the same judge filtered and scored the answers. I discarded it and
  added an independent, quote-verified auditor (`backend/results/rag_eval/preliminary/README.md`).
- Two voice unit tests silently depended on a real Sarvam key in a developer `.env`; they now patch a dummy key.
- Committed SQLite databases were removed from git.
